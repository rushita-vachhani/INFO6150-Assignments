# PulseLive – Concert Ticket Booking (Assignment 7)

## Overview
This is a 2-page responsive website for a concert ticket booking platform:
- `index.html` (Home / Browse Events)
- `book.html` (Event Details / Booking)

The site demonstrates:
- CSS Grid
- Flexbox
- Advanced SASS/SCSS features
- Modular SCSS architecture

---

## How to Run
1. Open `index.html` in any browser.
2. Compile SCSS → CSS with SASS:

```bash
npm install -g sass
sass scss/style.scss css/style.css
