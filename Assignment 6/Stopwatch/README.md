

## Features
- HH:MM:SS stopwatch with Start / Pause / Resume / Stop & Save / Reset
- Date picker and event name (required; disabled during run)
- History saved in `localStorage` (most recent first)
- Filter by date, plus stats (total sessions & total time)
- Async/Await + Promises + `setInterval`/`clearInterval`
- Responsive UI, inline errors, toast notifications

## How to run
Open `stopwatch.html` in a browser (serve locally if needed).
